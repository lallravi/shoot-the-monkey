# Shoot the Monkey

An interactive version of the classic "monkey and hunter" physics puzzle.

A hunter aims a dart rifle straight at a monkey hanging from a branch. The monkey lets go the moment it sees the flash. Does the dart still hit?

The page starts with six short slides that explain the physics for beginners:

- **Qualitative:** with no gravity the dart flies in a straight line. Gravity pulls the dart and the monkey down by the same amount, so aiming straight works.
- **Quantitative:** both fall ½·g·t² in time *t*. The slides include a worked example.

After the slides, students open the simulator. They can:

- change the dart speed, distance and height
- choose the gravity of Earth, the Moon, Mars, Jupiter or deep space
- show strobe snapshots of the flight
- read live ½gt² values
- hear sound effects

## Run it

Open `index.html` in a browser. No build step is needed.
